# Выгрузка отчётов

Отчёты формируются по текущим данным при каждом запросе и скачиваются в формате XLSX. Снимки отчётов в базе не хранятся. В каждой книге есть контекст отчёта и дата формирования.

Маршруты:

- `GET /api/reports/courses/{courseId}/xlsx` выгружает ведомость курса: работы и баллы с рейтингом для практики, посещаемость для лекций или баллы курсовой работы.
- `GET /api/reports/attendance-sheets/{sheetId}/xlsx` выгружает отдельную ведомость посещаемости.
- `GET /api/reports/coursework-sheets/{sheetId}/xlsx` выгружает результаты курсовых работ.
- `GET /api/reports/students/me/academic-record.xlsx` выгружает сводную успеваемость текущего студента за все курсы, в которых он числится.
- `GET /api/reports/students/{studentId}/academic-record.xlsx` доступен деканату для просмотра успеваемости указанного студента. Студент может запросить только собственную запись.
- `GET /api/reports/groups/{groupId}/ratings.xlsx` выгружает рейтинги студентов по практическим курсам группы.
- `GET /api/reports/debtors.xlsx` выгружает явно зафиксированные неудовлетворительные результаты.
- `GET /api/reports/statistics.xlsx` формирует книгу со статистикой по группам, курсам и специальностям, а также качеством знаний.

Преподаватель может выгружать только свои курсы и ведомости. Деканат может выгружать любые отчёты. Студенту доступна только собственная сводная успеваемость.

Должником считается студент с результатом «незачёт» либо итоговой оценкой ниже 3 в закрытой или архивной контрольной ведомости, а также студент с результатом ниже 50 баллов в закрытой или архивной ведомости курсовой работы. Отсутствующая оценка сама по себе задолженностью не считается. Пропуски лекций в список должников не включаются, так как решение о последствиях посещаемости принимает вуз.

Качество знаний рассчитывается как доля оценок 4 и 5 от всех итоговых числовых оценок за экзамены, дифференцированные зачёты и курсовые работы. Рейтинги практических курсов и результаты «зачёт/незачёт» в этот показатель не входят.

Сводная успеваемость строится по связям студента с курсами, поэтому включает результаты ранее пройденных курсов. Отдельный журнал переводов между группами система не хранит.
