# Бизнес-правила

Правила получены разбором того, как учёт успеваемости устроен в нашем вузе.
Там, где мы сознательно отступили от реальной практики или от текста задания,
это отмечено как **[решение команды]**.

## Курс

1. Работа принадлежит курсу и имеет максимальный балл. Сумма максимальных
   баллов по курсу произвольна — она не обязана равняться 100.
2. Как только работа появилась, у всех студентов группы по ней 0 баллов.
   Состояния «оценка не выставлена» не существует.
3. Рейтинг студента = набрано / максимум возможных × 100. Величина 0–100.
   Для курса без работ рейтинг не определён.
4. Баллы вносит и изменяет только преподаватель семинарной части курса,
   и только пока курс идёт. Работы редактируются на тех же условиях.
   **[решение команды]** Изменение максимального балла работы пересчитывает
   рейтинги всех студентов группы — это допускается, пока курс не завершён.

## Лекции и посещаемость

5. Лекционный преподаватель создаёт лекцию и отмечает для каждого студента
   `был` / `не был`.
6. Посещаемость можно вносить и изменять только пока курс идёт и ведомость
   посещаемости открыта. Для одной лекции и одного студента существует одна
   отметка.
7. Посещаемость хранится отдельно от баллов за работы, не входит в рейтинг и
   не влияет на итоговую оценку. Она используется в ведомости посещаемости и
   отчётах.

## Контроль

8. Результат итогового контроля вносится в зачётную ведомость. Для экзамена и
   дифференцированного зачёта преподаватель ставит балл 0–100. Неявка = 0,
   отдельного состояния «не явился» нет. Для обычного зачёта вносится
   `зачёт` / `незачёт`.
9. Результат контроля вносит преподаватель семинарной части курса.
10. Для экзамена и дифференцированного зачёта итоговый балл по дисциплине =
   (рейтинг курса + балл контроля) / 2. Для обычного зачёта итогом является
   `зачёт` / `незачёт`, рейтинг курса в расчёт не входит.
11. Итоговый балл переводится в оценку «5»–«2» по шкале перевода. Округление
   выполняется вниз. Шкалу задаёт преподаватель семинарной части курса. При закрытии
   зачётной ведомости шкала фиксируется, чтобы более поздняя правка не меняла
   уже сформированные итоговые оценки.
12. Зачётную ведомость нельзя закрыть, пока результат не внесён для каждого
   студента курса.

## Жизненный цикл

13. Курс: `ИДЁТ → ЗАВЕРШЁН`.
14. Ведомость посещаемости: `ОТКРЫТА → ЗАКРЫТА → АРХИВ`. Открыть можно только
    для курса, который идёт. После закрытия отметки менять нельзя.
15. Зачётная ведомость: `ОТКРЫТА ⇄ ЗАКРЫТА → АРХИВ`.
    Открыть можно только ведомость завершённого курса. Итоговая ведомость
    формируется на основании закрытой зачётной ведомости и курса.
    Из архива переходов нет.
16. Пересдача: деканат переоткрывает зачётную ведомость, преподаватель правит
    результат. Итоговая ведомость после этого пересчитывается.
    Курс при этом остаётся завершённым — семестровые баллы не пересдаются.
    След изменения сохраняет журнал действий.
    **[решение команды]** Пересдача возможна только в семестре, следующем
    за сессией. Дальше ведомость архивируется. В реальном вузе срок больше —
    мы сознательно сделали строже.

## Студент

17. Задолженность — отрицательный итог по дисциплине в закрытой зачётной
    ведомости.
18. Перевод студента в другую группу возможен только между семестрами и только
    при отсутствии задолженностей. Полученные ранее оценки остаются в курсах
    и ведомостях прежней группы; студент видит их в своей сводной успеваемости.
19. Студент видит только свои результаты. Чужие баллы, рейтинги и рейтинговый
    список группы ему недоступны.

## Общее

20. Вычисляемое не хранится. Рейтинги, итоги, оценки по шкале, итоговые и
    сводные ведомости, рейтинговые списки, отчёты о должниках и качестве знаний
    — это запросы к хранимым данным, а не отдельные таблицы.

## Известные ограничения

- Шкалу перевода задаёт каждый преподаватель сам, поэтому отчёт «качество
  знаний» по курсу или специальности сравнивает оценки, выставленные по разным
  шкалам. Так устроен вуз; система это не исправляет.
- Результат контроля как событие (ответ студента, ход экзамена и т. п.) в
  системе не хранится — преподаватель вносит готовый результат в зачётную
  ведомость. Обоснование оценки система показать не может, фиксируются только
  автор и время выставления.
