# Бизнес-правила

Правила получены разбором того, как учёт успеваемости устроен в нашем вузе.
Там, где мы сознательно отступили от реальной практики или от текста задания,
это отмечено как **[решение команды]**.

## Курс

1. Работа принадлежит курсу и имеет максимальный балл. Сумма максимальных
   баллов по курсу произвольна — она не обязана равняться 100.
2. Как только работа появилась, у всех студентов группы по ней 0 баллов.
   Состояния «оценка не выставлена» не существует.
3. Рейтинг студента = набрано / максимум возможных × 100. Величина 0–100.
   Для курса без работ рейтинг не определён.
4. Баллы вносит и изменяет только преподаватель, закреплённый за курсом,
   и только пока курс идёт. Работы редактируются на тех же условиях.
   **[решение команды]** Изменение максимального балла работы пересчитывает
   рейтинги всех студентов группы — это допускается, пока курс не завершён.

## Контроль

5. Экзамен и дифференцированный зачёт: преподаватель ставит балл 0–100.
   Неявка = 0, отдельного состояния «не явился» нет.
   Обычный зачёт: зачёт / незачёт.
6. Итог по дисциплине = (рейтинг курса + балл контроля) / 2.
   Для обычного зачёта итог булев, рейтинг курса в него не входит.
7. Оценка «5»–«2» выводится из итогового рейтинга по шкале перевода.
   Округление вниз. Шкалу задаёт преподаватель для своего курса.
   При закрытии ведомости шкала фиксируется в ней, чтобы более поздняя
   правка шкалы не меняла уже выставленные оценки.
8. Экзаменационную ведомость нельзя закрыть, пока хотя бы у одного студента
   результат не внесён.

## Жизненный цикл

9. Курс: `ИДЁТ → ЗАВЕРШЁН`.
10. Экзаменационная ведомость: `ОТКРЫТА ⇄ ЗАКРЫТА → АРХИВ`.
    Открыть можно только ведомость завершённого курса.
    Из архива переходов нет.
11. Пересдача: деканат переоткрывает ведомость, преподаватель правит результат.
    Курс при этом остаётся завершённым — семестровые баллы не пересдаются.
    След изменения сохраняет журнал действий.
    **[решение команды]** Пересдача возможна только в семестре, следующем
    за сессией. Дальше ведомость архивируется. В реальном вузе срок больше —
    мы сознательно сделали строже.

## Студент

12. Задолженность — отрицательный итог по дисциплине в закрытой ведомости.
13. Перевод студента в другую группу возможен только между семестрами и только
    при отсутствии задолженностей. Полученные ранее оценки остаются в курсах
    и ведомостях прежней группы; студент видит их в своей сводной успеваемости.
14. Студент видит только свои результаты. Чужие баллы, рейтинги и рейтинговый
    список группы ему недоступны.

## Общее

15. Вычисляемое не хранится. Рейтинги, итоги, оценки по шкале, сводные
    ведомости, рейтинговые списки, отчёты о должниках и качестве знаний —
    это запросы к хранимым данным, а не отдельные таблицы.

## Известные ограничения

- Шкалу перевода задаёт каждый преподаватель сам, поэтому отчёт «качество
  знаний» по курсу или специальности сравнивает оценки, выставленные по разным
  шкалам. Так устроен вуз; система это не исправляет.
- Результат экзамена как события (сдал/не сдал устно) в системе не хранится —
  преподаватель приходит с готовым решением. Обоснование оценки система
  показать не может, фиксируются только автор и время выставления.
