# Сценарии использования

Черновик Документа 3. Акторы и их цели.

## Преподаватель семинарного курса

1. Войти в систему
2. Просмотреть назначенные семинарные курсы с дисциплиной, группой и периодом
   от семестра начала до семестра окончания
3. Создать работу с максимальным баллом
4. Изменить или удалить работу, пока курс идёт
5. Просмотреть список студентов группы и их баллы
6. Выставить и изменить баллы за работу
7. Просмотреть рейтинг студентов по курсу
8. Завершить курс
9. Создать зачётную ведомость и задать шкалу перевода
10. Внести результат контроля в зачётную ведомость: балл за экзамен / диф.
   зачёт либо зачёт/незачёт
11. Закрыть зачётную ведомость
12. Просмотреть итоговую ведомость: рейтинг, результат контроля и итог по
    дисциплине
13. Выгрузить зачётную или итоговую ведомость на печать или в Excel

## Преподаватель лекционного курса

1. Войти в систему
2. Просмотреть назначенные лекционные курсы с периодом обучения
3. Добавить проведённую лекцию
4. Отметить для студентов `был` / `не был`
5. Исправить отметку посещаемости, пока курс идёт и ведомость открыта
6. Завершить лекционный курс после окончания занятий
7. Просмотреть и выгрузить ведомость посещаемости

## Преподаватель курсового курса

1. Войти в систему
2. Просмотреть назначенные курсовые курсы с дисциплиной, группой и периодом
3. Просмотреть список студентов курса
4. Внести или изменить балл за курсовую работу от 0 до 100, пока ведомость
   открыта
5. Завершить курсовой курс после окончания срока работы
6. Закрыть ведомость после внесения результата каждому студенту
7. Просмотреть результат курсовой работы по шкале оценивания

## Студент

Все сценарии доступны только для чтения и только для собственных данных.

1. Войти / выйти
2. Просмотреть свои курсы по дисциплинам и семестрам
3. Просмотреть работы по дисциплине и свои баллы
4. Просмотреть свой рейтинг по дисциплине
5. Просмотреть свою посещаемость на лекциях
6. Просмотреть свои итоговые оценки и задолженности
7. Просмотреть сводную успеваемость за всё обучение, включая прошлые группы

## Деканат

1. Вести справочники: студенты, группы, дисциплины, преподаватели
2. Назначить группе куратора из числа активных пользователей с ролью `DEAN`
3. Создать отдельный курс типа `LECTURE`, `SEMINAR` или `COURSEWORK`, назначив
   дисциплину, группу, преподавателя, семестр начала и семестр окончания
4. Перевести студента в другую группу
5. Изменить статус студента: академический отпуск, отчисление, восстановление
6. Просмотреть любые курсы, зачётные, итоговые ведомости и ведомости
   посещаемости и курсовых работ
7. Переоткрыть закрытую зачётную ведомость для пересдачи
8. Переоткрыть ведомость курсовых работ для пересдачи в следующем семестре
9. Просмотреть результаты курсов и посещаемость; самостоятельно принимать
   решения о последствиях пропусков лекций вне системы
10. Сформировать отчёты: рейтинговый список, посещаемость, должники, качество
   знаний, сводная по студенту, статистика по группам и специальностям

## Администратор

1. Управлять учётными записями
2. Назначать роли
3. Просматривать журнал действий пользователей
