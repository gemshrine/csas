# Ручное тестирование

Документ фиксирует ручные проверки системы и их результаты. Он пригодится для подготовки протокола испытаний и материалов к защите. Все действия выполняются через страницы приложения в браузере. Консоль разработчика и прямые запросы к API для обычной проверки не нужны.

Полный список сценариев находится в [плане тестирования](test-plan.md). Результаты ниже фиксируют уже выполненные укрупнённые проверки и сами по себе не означают, что каждый из 37 сценариев плана был пройден отдельно.

## Подготовка

Запустить приложение с демонстрационными данными по инструкции из `docs/development.md` и открыть `http://localhost:8080`. Демо-учётные записи и пароли приведены в том же документе.

При проверке операций, которые меняют данные, использовать dev-базу. Созданные записи и изменения сохраняются между запусками.
