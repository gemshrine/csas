# Глоссарий (единый язык)

Одно понятие — одно слово. В коде, в документах и в разговоре используем
одинаковые термины. Если термина не хватает — сначала добавляем сюда,
потом пишем код.

| Термин | Значение | Чем НЕ является |
|---|---|---|
| **Курс** | Преподавание одной дисциплины одной группе в одном семестре. У курса отдельно назначаются преподаватель семинарной части и преподаватель лекционной части. | Не дисциплина. Дисциплина одна, курсов по ней много. |
| **Дисциплина** | Учебный предмет: название, часы, форма контроля. Справочник. | Не курс. Сама по себе никого не учит. |
| **Работа** | Оцениваемое мероприятие внутри курса: лабораторная, практика, контрольная, курсовая. Имеет название, дату и максимальный балл. | Не «задание к сдаче». Студент ничего не загружает в систему. |
| **Лекционная часть** | Часть курса, в которой преподаватель проводит лекции и отмечает посещаемость студентов. | Не семинарная часть и не источник рейтинга. |
| **Семинарная часть** | Часть курса, в которой преподаватель проводит семинары, принимает работы и выставляет баллы. | Не лекционная часть. |
| **Лекция** | Проведённое занятие лекционной части курса, для которого фиксируется посещаемость студентов. | Не работа и не балл. |
| **Ведомость посещаемости** | Документ с лекциями курса и отметками `был` / `не был` для каждого студента. | Не зачётная ведомость и не источник итоговой оценки. |
| **Посещаемость** | Отметка присутствия студента на конкретной лекции. | Не балл и не оценка. |
| **Балл** | Количество баллов студента за конкретную работу, от 0 до максимума работы. | Не оценка «5»/«4». |
| **Рейтинг** | Величина 0–100. Доля набранных баллов от максимально возможных. | Не место в списке. |
| **Рейтинговый список** | Студенты группы, упорядоченные по рейтингу. Отчёт. | Не «рейтинг». |
| **Зачётная ведомость** | Ведомость промежуточной аттестации, в которую преподаватель семинарной части вносит результат контроля: балл 0–100 для экзамена и диф. зачёта либо зачёт/незачёт. | Не ведомость посещаемости и не итоговая ведомость. |
| **Итоговая ведомость** | Документ с итогом по дисциплине. Для экзамена и диф. зачёта итоговый балл считается как (рейтинг + результат контроля) / 2 и переводится в оценку 2–5; для зачёта переносится зачёт/незачёт. | Не источник исходных баллов. |
| **Результат контроля** | Что преподаватель поставил в зачётной ведомости: балл 0–100 (экзамен, диф. зачёт) либо зачёт/незачёт. | Не итог. Итог вычисляется в итоговой ведомости. |
| **Итог по дисциплине** | Результат, попадающий в итоговую ведомость: оценка 2–5 для экзамена и диф. зачёта либо зачёт/незачёт. | Не самостоятельная исходная оценка. |
| **Шкала перевода** | Соответствие итогового рейтинга оценке «5»–«2». Задаётся преподавателем для курса. | Не общевузовская константа. |
| **Задолженность** | Отрицательный итог по дисциплине в закрытой ведомости. | — |
| **Семестр** | Учебный период. К нему привязан курс. | — |

## Слова, которых в коде быть не должно

- **«Сайт дисциплины»** — так это называют у нас в вузе, но это название экрана.
  В домене — **Курс**.
- **«Ведомость»** без уточнения — их несколько по смыслу. Нужно говорить
  «зачётная ведомость», «ведомость посещаемости» или «итоговая ведомость».
- **«Оценка»** как самостоятельная сущность — оценок отдельно от курса и
  ведомости не существует.
